# Repository Instructions

## Web UI changes

Before changing UI code under `archinsight-web` or
`packages/archinsight-workbench`, read and follow
[`docs/development/ui.md`](docs/development/ui.md).

## Insight language changes

Before changing Insight syntax, semantics, type definitions, linking,
completion, highlighting, queries, or language-facing editor behavior, read
and follow [`docs/development/language.md`](docs/development/language.md).

## Tests

Before changing test infrastructure or adding a new behavior family, read and
follow [`docs/development/testing.md`](docs/development/testing.md).
